# 🌗 Day Light

كل يوم نقطة ضوء… لونها إنت اللي بتحددها.

تطبيق ويب بسيط لمتابعة أهدافك اليومية: لو حققت هدفك النهاردة يتلوّن يومك بالأخضر، ولو لأ يتلوّن بالأحمر — لكن بدل ما يوقف عند اللون بس، بيسألك إيه اللي وقف قدامك وبيدّيك اختيارات للحل (تسأل حد / تحلها بنفسك / تكتب حل بنفسك)، وكل خطوة ممكن تتخطاها.

## المميزات
- تسجيل يوم يومي (أخضر/أحمر) بأنميشن بسيط عند الاختيار
- عند "لأ": وصف المشكلة ثم اختيار طريقة الحل
- أرشيف لكل الأيام السابقة مع تفاصيلها
- عداد أيام متتالية (🔥 streak)
- تصميم عربي (RTL) بالكامل
- PWA جاهز للتثبيت على الشاشة الرئيسية لأي جهاز (موبايل/لابتوب)

## تشغيله على جهازك (للمطورين)

يحتاج [Node.js](https://nodejs.org) مثبّت عندك (نسخة 18 أو أحدث).

```bash
# 1. نزّل المشروع
git clone https://github.com/YOUR-USERNAME/day-light-app.git
cd day-light-app

# 2. ثبّت المكتبات
npm install

# 3. شغّله محليًا للتجربة
npm run dev
# هيديك رابط زي http://localhost:5173

# 4. ابنِ نسخة جاهزة للنشر
npm run build
# هيطلعلك فولدر باسم dist جاهز يترفع لأي استضافة
```

## نشره أونلاين (بدون أي خبرة برمجية)

بعد `npm run build`:

1. افتح https://app.netlify.com/drop
2. اسحب فولدر `dist` بس (مش المشروع كله)
3. هيديك رابط شغال خلال ثواني، وتقدر "تضيفه للشاشة الرئيسية" من موبايلك زي أي تطبيق
